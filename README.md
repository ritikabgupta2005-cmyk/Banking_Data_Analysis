# Banking Data Analysis

# Overview

A data analytics project focused on analyzing banking data to explore customer information, account balances, transactions, loans, and banking operations.

The project was developed using MySQL to manage the database, perform SQL queries, and analyze banking records.

# Tools Used

* **MySQL** – Database creation, data management, and analysis
* **MySQL Workbench** – Writing and executing SQL queries
* **SQL** – Data filtering, aggregation, joins, subqueries, and analytical queries

# Analysis

The SQL analysis includes:

* Customer and account information analysis
* Account balance and account type analysis
* Transaction analysis and filtering
* Loan amount comparison and ranking
* Customer, account, and transaction relationships
* Aggregate analysis using SUM, AVG, MIN, MAX, and COUNT
* Advanced SQL queries using joins and subqueries
* Window functions for ranking and running totals
* Views for retrieving high-balance accounts

# Key Insights

* Analyzed account balances and compared balances across account types.
* Identified accounts with balances above specified thresholds and the average balance.
* Calculated total, average, highest, and lowest account balances.
* Examined transactions associated with different accounts.
* Compared transaction amounts with the average transaction amount.
* Ranked loans based on loan amounts.
* Used SQL joins and subqueries to explore relationships between banking records.
